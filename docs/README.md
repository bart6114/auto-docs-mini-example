# Click-a-Duck handbook

This directory is a standard Docusaurus 3 site. Repository-level setup and the documentation automation walkthrough live in the root `README.md`.

```bash
npm ci
npm start
```

Use `npm run typecheck && npm run build` for the production checks. The build also generates `llms.txt`, `llms-full.txt`, and Markdown copies of handbook pages under `build/`.
